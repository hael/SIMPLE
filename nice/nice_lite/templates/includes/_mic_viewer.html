{% comment %} _mic_viewer.html — titled panel of micrograph tiles plus the per-half-image contrast/brightness menus and shared scale/sort/select-above-below menu. Expects `panel_title` (str) and either `jobstats.latest_micrographs` (stream pages) or `jobstats.micrographs` (batch pages) — a list of micrograph entries, each with dfx/dfy/ctfres/path — in context. Optional `selectable` (bool): when true, tiles are click-selectable, select-above/select-below are offered in the context menus, and the selection report (counts, select-all/ deselect-all/invert) is shown; used from batch pages only, not from the stream zoom pages. Optional `hide_pspec` (bool): when true, tiles render the micrograph half only (no power-spectrum half or its context menu). Includes `_mic_selection_element.html` per tile, `_mic_selection_controls.html` for the mic/pspec contrast-brightness menus (shared scale/sort/select-above- below), and, when selectable, `_mic_selection_report.html` for selection counts/select-all controls and the mic/pspec show/hide toggles. Owns the tile toggling and sort JS (toggleMic/updateMicSelectionBorder/ sortMicDefocus/sortMicCtfRes/selectAboveMic/selectBelowMic) and the pick-box overlay drawing (drawMicBoxOverlays), redrawn on load/resize and whenever a mic image finishes loading or updateMicScale resizes tiles; relies on a page-level `lastinteraction` global declared by the including page's own script. Only one instance is ever rendered per page. {% endcomment %}
