{% comment %} _mic_selection_controls.html — two context menus for the micrograph tile grid: one opened from a tile's micrograph half, one from its power-spectrum half (see oncontextmenu on each half in _mic_selection_element.html). Each menu's contrast/brightness sliders control only that image type (CSS vars --preprocess-contrast-mic/-pspec and --preprocess-brightness-mic/-pspec); sort-on-defocus, sort-on-CTF-resolution, scale, and (when `selectable`) select-above/select-below are shared/global and appear identically in both menus. Self-contained: wired up by name/data attributes; opened via showMicMenu(this, event, 'mic'|'pspec'). Function names are Mic-prefixed so they don't collide with _cls2D_viewer.html's identically-purposed functions when both panels render on the same batch page. sortMicDefocus/ sortMicCtfRes/selectAboveMic/selectBelowMic are owned by _mic_viewer.html; relies on a page-level `lastinteraction` global declared by the including page's own script. Optional `hide_pspec` (bool): omits the power-spectrum menu, matching tiles rendered without a pspec half. {% endcomment %}
