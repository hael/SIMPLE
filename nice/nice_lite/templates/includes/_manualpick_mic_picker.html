{% comment %} _manualpick_mic_picker.html — full-size display of the micrograph currently selected in _manualpick_mic_selector.html, filling its container. Shows a placeholder until a tile is selected. toggleMic (in _manualpick_mic_selector.html) calls showSelectedMic(micIdx, ...) with the clicked tile's index/image src/box overlay data; the overlay canvas reuses the boxes-overlay class so drawMicBoxOverlays (also owned by that file) draws its picks automatically. Clicking the image (pickMicCoordinate) converts the click to mic-scale coordinates and adds it as a pick. Picks are kept in manualPickedBoxes, keyed by micrograph.i, so they survive switching to another mic and back, and saved (overwriting the mic's box file) via save_batch_manual_pick_boxes whenever a mic is left or the save button is clicked. Box size/shape are controlled by _manualpick_pick_controls.html, included in the header below. The shared _single_micrograph_view.html owns only the image display; this partial attaches the picking canvas and click handler. {% endcomment %}
