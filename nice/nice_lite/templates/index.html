{% comment %} stream.html — outer shell for the SIMPLE Stream interface. Structure: - Fixed header bar: logo, project/workspace selectors, classic/logout actions. - Full-height iframe: loads the workspace view (stream list and details) at iframeurl, or remains blank until a project and workspace are selected. - messages.html: renders any Django flash messages. Context variables: projects — queryset of all projects available to this user workspaces — queryset of workspaces for the selected project current_project_id — id of the currently selected project (0 = none) current_workspace_id — id of the currently selected workspace (0 = none) iframeurl — URL to load inside the content iframe, or None Selecting a project or workspace submits a GET form, reloading the page with the new selection reflected in the URL query string. Per-tab persistence: the resolved project and each project's most recently used workspace are cached in this tab's sessionStorage. On a bare load (no selected_*_id in the URL) any id missing from sessionStorage falls back to the selected_*_id cookie set server-side, but a value present in sessionStorage always wins over that cookie. {% endcomment %} {% load static %} SIMPLE Stream
